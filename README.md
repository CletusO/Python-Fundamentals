# Basic Python Exercises

Early learning exercises demonstrating Python fundamentals.

## Files

### `mycalculator.py`
Basic calculator supporting addition, subtraction, multiplication, and division with multiple numbers.

**Concepts:** Functions, loops, dictionaries, user input, error handling

### `letter_count.py`
Program to count letter frequency in a sentence.

**Concepts:** Classes, dictionaries, string manipulation

### `Bus.py`
Real-time bus arrival display system using datetime and classes.

**Concepts:** Object-oriented programming, datetime manipulation, recursion, data structures

### `number_guessing_game.py` (assignment.py)
Interactive number guessing game with limited tries.

**Concepts:** Random number generation, loops, conditionals, error handling, user input validation

### `Christmastree.py`
ASCII art Christmas tree generator.

**Concepts:** String manipulation, loops, pattern generation

## What I Learned

- Writing clean, documented code
- Basic error handling with try/except
- Object-oriented programming principles
- User input validation
- Working with Python's standard library (random, datetime)

## Limitations & Areas for Improvement

- No unit tests
- Basic error handling could be more robust
- Could use type hints for better code clarity
- Some functions could be refactored for better reusability
